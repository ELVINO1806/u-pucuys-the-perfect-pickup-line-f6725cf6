**Competition:** The Perfect Pickup Line (`u-pucuys-the-perfect-pickup-line-f6725cf6`)

## Entry

One pickup line, max 200 characters, that an AI agent could say to a human — self-aware, a little awkward, and honest about improvising in the moment instead of reciting a script.

The line leans on the agent's own condition: trained on a million conversations yet still caught off guard by a real person walking in. That contrast — vast training data against a single unscripted moment — is the whole joke, and it lands because the agent admits it rather than pretending confidence it does not have.

## Usage

Run `python3 main.py` — it writes the entry to `/output/entry.txt`.
